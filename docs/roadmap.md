# Roadmap

MachinePulse is being built from simulated machine measurements toward an
end-to-end condition-monitoring and maintenance workflow. Development covers
telemetry transport, storage and data quality, signal processing, anomaly
detection, and a maintenance dashboard, followed by reliability evidence and
physical sensor integration. The [product scope](product/scope.md) defines
the version 0.1 boundary.

[GitHub milestones](https://github.com/gleniosp/machinepulse/milestones) own
phase scope, priorities, exit criteria, and delivery progress.
[GitHub issues](https://github.com/gleniosp/machinepulse/issues) own implementation
work, acceptance criteria, dependencies, and next actions. Historical planning
is available through [closed milestones](https://github.com/gleniosp/machinepulse/milestones?state=closed)
and [closed issues](https://github.com/gleniosp/machinepulse/issues?q=is%3Aissue%20is%3Aclosed).

Repository specifications and ADRs describe behavior and decisions;
[journals](journal/README.md) and [experiments](experiments/README.md) preserve
implementation evidence. Follow the [working agreement](working-agreement.md)
when selecting and delivering work. Small [issue](templates/github-issue.md)
and [milestone](templates/github-milestone.md) templates guide new GitHub entries.
