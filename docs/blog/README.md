# Technical Articles

This directory contains polished article drafts derived from the engineering journal. Articles should be useful on their own, not merely chronological project updates.

## Article principles

Each article should:

- start with a technical question or problem;
- explain enough domain context to be understandable;
- show concrete artifacts such as diagrams, plots, measurements, or code;
- distinguish facts, assumptions, and experimental results;
- discuss limitations and failed approaches;
- link to the relevant MachinePulse specification and implementation; and
- avoid presenting synthetic behavior as validated industrial truth.

## Article workflow

```text
journal notes
    → article outline
    → evidence and figures
    → polished draft
    → review for accuracy and licensing
    → external publication
    → published-link update
```

The repository can keep the source draft even if the canonical published version lives elsewhere.
