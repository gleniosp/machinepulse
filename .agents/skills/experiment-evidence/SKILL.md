# Experiment Evidence

Use this skill when answering an uncertain technical or domain question with a
measured run, generated data, plots, benchmarks, or failure evidence. It is for
experiments, not ordinary implementation tests or unsupported product claims.

## Route the work

1. Read [the experiment guidance](../../../docs/experiments/README.md) and
   [the experiment template](../../../docs/experiments/template.md).
2. Read the owning specification, task, and relevant architecture or contract.
3. Define one question, a falsifiable hypothesis when useful, a small setup,
   and a next action before changing parameters.
4. Keep the experiment reproducible and proportionate to the decision it must
   inform.

Use the lifecycle:

```text
Question → Hypothesis → Setup → Run → Results → Interpretation → Next action
```
